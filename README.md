# Gene Expression Analysis

## Description
This project analyzes a sample gene expression CSV file and identifies the top 10 expressed genes based on their expression values.

## Input File
- gene_expression.csv

## Python Script
- gene_expression_analysis.py

## Method
The Python script:
1. Reads the gene expression CSV file.
2. Extracts gene names and expression values.
3. Sorts the genes based on expression level in descending order.
4. Identifies the top 10 expressed genes.
5. Displays the results.
